# Metric Definitions

All metrics below follow the portfolio dashboard's analysis convention. Date range, platform, and store filters must be held consistent when comparing periods.

| Metric | Definition / calculation | Interpretation |
|---|---|---|
| GMV | Gross merchandise value generated by completed/valid orders in the selected scope. | Scale of transaction value; it is not merchant profit. |
| Valid orders | Orders counted as valid under the project’s order-status rule. | Demand and fulfilment volume used alongside GMV. |
| Merchant receipts | Amount received by the merchant under the available settlement/receipt fields. | A closer operating-receipt view than GMV, but still not profit. |
| Average order value | GMV ÷ valid orders. | Value per order; changes can affect GMV even when order volume is stable. |
| Subsidy rate | Subsidy amount ÷ GMV, where subsidy data are available in the selected scope. | Promotional intensity relative to transaction value. |
| CPC spend | Actual paid-media spend billed under the platform’s CPC delivery model. | Traffic-acquisition investment. |
| GMV ROI | Platform-attributed GMV ÷ CPC spend. | Transaction-value return per unit of paid-media spend. |
| Merchant-receipt ROI | Merchant receipts attributable under the project convention ÷ CPC spend. | Receipt-based return per unit of spend; not a profit margin. |
| Cost per click | CPC spend ÷ clicks. | Unit cost of acquiring a visit. |
| Order conversion rate | Valid orders ÷ clicks. | Efficiency from paid click to valid order. |
| GMV per order | GMV ÷ valid orders. | Transaction value of a converted order. |
| Store GMV contribution | A store’s GMV ÷ total GMV in the selected scope. | Concentration and prioritisation signal, not a measure of store profitability. |

## Use notes

- GMV ROI and merchant-receipt ROI are efficiency indicators, not proof that media spend caused all attributed sales.
- A change in ROI should be read with cost per click, conversion rate, and GMV per order before an action is chosen.
- Merchant receipts exclude any unobserved operating costs; avoid describing this metric as net profit.
