# 指标定义

以下指标遵循本作品集看板的分析口径。进行期间、平台或门店比较时，应保持日期范围与筛选条件一致。

| 指标 | 定义 / 计算方式 | 解读 |
|---|---|---|
| GMV | 所选范围内已完成/有效订单产生的交易总额。 | 衡量交易规模，不等于商家利润。 |
| 有效订单 | 按项目订单状态规则计入的订单数。 | 与 GMV 配合观察需求与履约量。 |
| 商家实收 | 基于可获得结算/实收字段计算的商家收到金额。 | 比 GMV 更接近经营收入，但仍不等于利润。 |
| 客单价 | GMV ÷ 有效订单。 | 单笔订单价值；订单量稳定时仍可能推动或拉低 GMV。 |
| 补贴率 | 补贴金额 ÷ GMV（在所选范围有补贴数据时）。 | 相对交易额的促销力度。 |
| CPC 费用 | 平台按 CPC 投放模式实际计费的费用。 | 获取流量的投入。 |
| GMV 投产比 | 平台归因 GMV ÷ CPC 费用。 | 每单位投放费用带来的交易额回报。 |
| 实收投产比 | 按项目归因口径的商家实收 ÷ CPC 费用。 | 每单位投放费用带来的实收回报，不是利润率。 |
| 点击成本 | CPC 费用 ÷ 点击量。 | 获取一次点击的单位成本。 |
| 下单转化率 | 有效订单 ÷ 点击量。 | 从付费点击到有效订单的效率。 |
| 单均 GMV | GMV ÷ 有效订单。 | 每笔有效订单的交易价值。 |
| 门店 GMV 贡献 | 单店 GMV ÷ 所选范围总 GMV。 | 识别集中度与优先级，不衡量门店利润。 |

## 使用说明

- GMV 投产比与实收投产比是效率指标，并不能证明投放导致了全部被归因的销售。
- 投产比变化应结合点击成本、下单转化率和单均 GMV 后再决定行动。
- 商家实收未扣除所有不可观察的经营成本，不应表述为净利润。
